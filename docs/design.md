# liteOS 设计文档

> 一切皆运动。基座只管运动控制，无状态，可被任意大脑骑乘。

**语言 / Languages:** **中文** · [English](design.en.md)

---

## 0. 定位

liteOS 不是"一个操作系统"，而是一个**基座**：一个只管运动控制、无状态、可被任意上层大脑骑乘的底座。

| 层 | 角色 | 特征 |
|---|---|---|
| **上层大脑** | 意图、策略、智能 | 可热插拔，随时替换 |
| **基座** | 只做运动控制 | 唯一不变、唯一可信、无状态 |
| **物件** | 物理世界 | 即插即用，受基座控制运动 |

---

## 1. 本体论：一切皆运动

1. 万事万物都是运动
2. 没有运动，物件不存在
3. **静止是一种相对的运动**

### 第 3 条是整个设计的支点

它的推论：

- 「静止」不是运动的一个取值，而是**一次比较的结果**
- 比较需要**参照系**，参照系是**信息**
- 基座不保存信息 ⇒ **判定「静止 / 运动」不在基座职责内**

**因此：判定归大脑，施加归基座。**

---

## 2. 唯一原语：施加运动

由第 1 条推到底：

> **基座只有一个指令：施加运动。**
> 没有「停止」这个指令 —— 「静止」就是「以参照系的运动为自身的运动」。

| 意图 | 基座实际执行 |
|---|---|
| 让它运动 | `施加运动(物件, 运动, 参照系, 时长)` |
| 让它静止 | `施加运动(物件, 与参照系同步, 时长)` |

**两行是同一个操作，只是参照系不同。**

基座**永远不区分**「运动」与「静止」，因此基座里没有 `MOVING` / `STILL` 这两个枚举值，一个都不需要。

> 状态机消失了，只剩一个函数。

---

## 3. 基座：无状态的运动控制函数

```
基座 = f(自描述的运动控制事件) → 对物件施加运动
```

### 3.1 无状态，因此事件必须自描述

基座不保存信息 ⇒ 没有可用的参照系 ⇒ 每条事件必须自带上下文。

> **运动控制事件是自描述的**：自带目标、运动内容、参照系、时长。

这是无状态基座能够成立的**全部秘密**：它不需要记忆，因为**每个事件自带一个世界**。

反过来看也成立：**基座之所以能无状态，恰恰因为「静止」是相对的** —— 参照系可以从事件里来，不必从基座里来。

### 3.1.1 `duration_ns` 的语义：拾取器模型

`duration_ns` 表示**这条事件的有效时长**（拾取器模型），而非「持续推多久」（遥控器模型）。

| 模型 | 语义 | 事件结束后 |
|---|---|---|
| 遥控器 / remote control | 持续推，松手即回落 | 物件回到默认状态 |
| **拾取器 / pick-and-place** | **把物件放到一条轨道上** | **物件继续沿轨道运动** |

**采用拾取器模型。** 理由：它与已确认的设计决定完全一致。

| 设计决定 | 拾取器模型如何满足 |
|---|---|
| 基座无状态 | 事件结束后基座无需维持任何东西 |
| 物件自带运动能力 | 物件自己继续沿轨道运动 |
| 大脑可热插拔 | 大脑断开时，世界不会瞬间静止，而是继续跑完自己的事件 |

> **事件有一条生命长度；生命结束后，物件仍在运动。**

### 3.1.2 运动控制事件的形状

```c
/* 设计示意 */
#define MOTION_DOF_MAX 6

typedef struct {
    u64 wire;                    /* 目标：接线句柄；0 无效 */
    u64 frame;                   /* 参照系：另一条接线；0 = 世界系 */
    u64 duration_ns;             /* 事件有效期（拾取器模型） */
    u8  dof;                     /* 有效分量数，≤ 6 */
    s64 motion[MOTION_DOF_MAX];  /* 相对运动，定点表示 */
} motion_event_t;
```

五个字段对应唯一原语的参数，一个不多一个不少。

**关键：`motion` 是「相对 frame 的运动」。**

于是「静止」不需要单独指令：

| 想要的 | 事件 |
|---|---|
| 绝对静止 | `motion = 0, frame = 世界` |
| 随物件 X 一起动（相对静止） | `motion = 0, frame = X 的接线` |
| 以速度 v 运动 | `motion = v, frame = 世界` |

**静止 = `motion` 取 0。** 这就是「静止是一种相对的运动」在代码里的确切落点。

三条纪律：

1. **没有 opaque 载荷。** 事件里不允许夹带任何非运动数据 —— 「其他一切信息」必须走物件与大脑的直连通道，不得借道基座。这是纪律，不是疏漏。
2. **定点而非浮点。** 基座不碰浮点，避免 FPU 状态保存，也保证 WCET 可静态分析。
3. **参照系就是另一条接线。** 基座因此无需保存任何参照系定义：`frame` 只是一个接线句柄，基座现场校验它当前是否有效。

### 3.2 无状态的边界：接线 vs 信息

| | **接线** | **信息** |
|---|---|---|
| 是什么 | 哪个物件挂在哪个口 | 世界的内容 |
| 例子 | 端口 → 物件的通道 | 位置、速度、意图、图像 |
| 基座持有 | **是** | **否** |
| 类比 | 交换机知道哪条线接到哪个号码 | 交换机不知道你们在聊什么 |

> **接线是执行的必要条件；信息是世界的内容。**
> 基座可以持有前者，绝不持有后者。

### 3.3 基座有什么

```
├── 接线        物件与端口的对应（瞬态管线）
├── 施加运动    唯一原语
├── 接入 / 拔出  接线的变更
├── 执行瞬态    事件存续期间的计时等执行状态（非世界信息）
└── 隔离        物件之间、大脑与物件之间的边界
```

### 3.4 基座没有什么

```
世界状态         物件状态表        查询接口
静止/运动判定     参照系与上下文     控制律与策略
日志             文件系统          网络栈
驱动模型         用户管理          图形
```

### 3.5 基座是运动控制的唯一通路

所有运动控制必须经过基座。这使基座成为世界运动的唯一执行者，**同时不需要它保存任何世界信息**。

## 4. 上层大脑

- **可热插拔，无缝**
- 只与基座在**运动控制**这一件事上发生关系
- 负责**判定**：静止还是运动（因为需要参照系，而参照系是信息）
- 负责**意图与策略**：为什么动、该怎么动
- 其余一切：与物件**直连**

### 大脑无缝靠什么

基座无状态，因此**大脑的现场不在基座**，而在**物件**。

新大脑接上后，直接向物件读取现场 —— 这之所以可行，正因为「物件直连大脑」。

> **大脑的无缝，靠的是物件即记忆。**

---

## 5. 物件

- 即插即用，热插拔
- 运动受基座控制
- 其他信息与大脑直连
- 自带运动能力（自己的驱动与闭环）
- **不定义对错**：它只被施加运动，并向上报告

---

## 6. 两种热插拔的异同

**相同点只有一条**：都是热插拔 —— 接入与离开都不需要停机。其余全部不同。

| | 物件热插拔 | 大脑热插拔 |
|---|---|---|
| 无缝的含义 | **身体不中断** | **意识不中断** |
| 谁保证 | 基座（识别并纳入控制） | 基座（持续运行） |
| 状态的所在 | 物件自己 | 物件（大脑去读） |
| 断了的后果 | 物理事故 | 变呆，不变危 |
| 技术难点 | 物理连续性 | 认知连续性（语言统一） |
| 定义正确？ | 否 | 是 |
| 换了什么 | 世界的肢体 | 世界的价值观 |

> **物件无缝是身体不中断，大脑无缝是意识不中断。**
> 前者靠物件的自主，后者靠物件的记忆。

---

## 7. 通道模型：运动是唯一窄腰

```
              上层大脑（可热插拔）
              ╱                    ╲
   运动控制（唯一通路，自描述）      其他一切信息（直连）
            ╱                          ╲
           ▼                            ▼
    ┌─────────────┐                 ┌────────┐
    │   基座       │   施加运动       │  物件   │
    │  无状态      ├────────────────▶│        │
    └─────────────┘                 └────────┘
```

就像 IP 是网络的窄腰 —— 所有应用都从它上面过，但应用之间通信不靠它。

| 通道 | 内容 | 是否经过基座 |
|---|---|---|
| 运动控制 | 自描述的运动事件 | **必须** |
| 其他一切 | 传感、意图、图像、数据 | **不经过** |

---

## 8. 已确认的设计决定

1. 基座自己就是一个大脑，只做运动控制这一件事
2. 基座**无状态**，不保存信息
3. 基座持有**接线**（管线），不持有**信息**（内容）
4. 基座是运动控制的**唯一通路**
5. 运动控制事件**自描述**（自带参照系与时长）
6. 唯一原语是**施加运动**；「静止」是参照系取自身运动的结果
7. 上层大脑可热插拔、无缝；只与基座在运动控制上发生关系
8. 其他一切信息：物件与大脑**直连**
9. 静止 / 运动的判定属于大脑，不属于基座
10. `duration_ns` 采用**拾取器模型**：事件有效时长，事件结束后物件继续沿轨道运动
11. 运动控制事件是**定点、无载荷、自描述**的：`{wire, frame, duration_ns, dof, motion[]}`
12. `motion` 表示**相对 frame 的运动**；「静止」即 `motion = 0`
